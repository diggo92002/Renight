# 夜聲｜睡前聲音播放器

一個免安裝套件的單頁睡前聲音工具。使用瀏覽器 Web Audio API 即時產生雙耳節拍與背景底噪。

## 功能

- Delta、Theta、Alpha 節拍預設與可調頻率
- 可選音調、音量與播放時間
- 計時結束前會逐漸淡出
- 可混合棕色、粉紅或白噪音
- 設定保存在目前瀏覽器的本機儲存空間
- 手機版排版，支援加入手機主畫面

## 使用方式

直接用瀏覽器開啟 `index.html` 即可。若要發布到網路，可將此資料夾推送到 GitHub，並在 GitHub Pages 設定中選擇部署來源。發布後使用 HTTPS 網址開啟，再透過瀏覽器選單加入主畫面；iPhone/iPad 可在 Safari 使用「加入主畫面」。

雙耳節拍需要立體聲耳機。建議從低音量開始，若聆聽時感到不舒服請停止。這是放鬆用途的聲音工具，不是醫療產品，也不保證改善睡眠。

## 專案檔案

- `index.html`：播放器頁面與音訊邏輯
- `manifest.webmanifest`：手機主畫面安裝資訊
- `icon.png`：高解析度手機與瀏覽器圖示（1254 × 1254 PNG）
- `icon-192.png`、`icon-512.png`：PWA 安裝圖示尺寸
